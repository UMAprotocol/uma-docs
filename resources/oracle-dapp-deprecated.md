# Oracle Dapp (Deprecated)

The Oracle dapp has been deprecated. Requests on the Polygon ManagedOptimisticOracleV2 contract can be viewed, proposed, and disputed on the new [Explorer dapp](https://explorer.uma.xyz/).&#x20;

All other oracle contracts can be viewed and interacted with onchain. The Oracle dapp's code is open source and can be viewed or forked from [here](https://github.com/UMAprotocol/optimistic-oracle-dapp-v2/tree/pre-deprecation-record).
